# 🎧 MoodMuse: The AI Mood Recommender

Welcome to **MoodMuse** – your personal AI-powered mood matcher that knows just what you need to hear and hear 🎶  
Whether you're feeling happy, sad, angry, or somewhere in between, MoodMuse has a vibe for that 💜

---

## 💡 What is MoodMuse?

**MoodMuse** is a light-weight AI agent built with [Streamlit](https://streamlit.io) that takes your current mood as input and recommends:

- ✨ A handpicked inspirational **quote**
- 🎵 A mood-matching **song suggestion**

No login, no API key, no fluff – just instant emotional support with a vibe. Designed to be simple, fast, and soothing.

---

## 🛠️ Tech Stack

- **Frontend & Backend**: [Streamlit](https://streamlit.io)
- **Language**: Python 🐍
- **Deployed on**: [Streamlit Cloud](https://streamlit.io/cloud)

---

## 🤖 How It Works

1. Type how you're feeling today (e.g., *happy*, *sad*, *anxious*)
2. MoodMuse matches it to a curated set of quotes & songs
3. Enjoy your mood boost 💫
